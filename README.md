Clearout is a modern uninstaller for Windows. It shows everything installed on your PC, removes programs with one click, and then finds the files they leave behind so you can clear those out too.

What it can do

See everything. Your desktop programs and Microsoft Store apps in one clean list, with icons, size and install date. Search by name or publisher, filter by Large, Recently installed or Store apps, and sort by name, size or date.

Uninstall one or many. Click Uninstall on a row, or tick several programs and remove them in one go. Each program's own uninstaller does the work, and Clearout checks that the program really disappeared. It tells you clearly when an uninstall was cancelled or failed. A silent mode skips the uninstaller windows when a program supports it.

Clear out leftovers. After an uninstall, Clearout looks for files the program left behind, such as install folders, shortcuts, and settings in AppData. You tick what you want gone, and only those items move to the Recycle Bin. Settings and saved data are never ticked for you.

Remove broken entries. If a program is gone but still shows in Windows, or its uninstaller is missing, you can remove its entry from the list. A backup of the entry is saved first.

History. See what you removed and how much space you freed.

Looks like a modern app. A clean window with a light or dark theme that follows Windows, and six accent colors to choose from. Press Ctrl and F to search from anywhere.

Export. Save your program list as a CSV file.

Built to be careful

Clearout never deletes program files by itself. That is left to each program's own uninstaller. Leftovers go to the Recycle Bin so you can restore them. It refuses to touch Windows folders, your Documents, Downloads and Pictures, and the main AppData folders. It never offers a folder that belongs to another program you still have installed. Your settings and history stay on your PC.

How to install

Download and run Clearout-Setup. You do not need administrator rights to install it. Open Clearout from the Start menu. Some programs need administrator rights to be removed. When that happens, Clearout shows a bar with a Restart as administrator button. To remove Clearout, open Windows Settings, then Apps, then Clearout, and choose Uninstall.

Good to know

Microsoft Store apps are removed for your user account only.

Very large items may be deleted permanently by Windows if they do not fit in your Recycle Bin. Clearout warns you before you confirm.

Some programs show their own windows while uninstalling. Follow their steps, or turn on silent mode.

The installer is not code-signed, so Windows may show a "protected your PC" notice. Click More info, then Run anyway.

Clearout works on Windows 10 and 11.
